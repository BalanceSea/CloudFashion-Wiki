# ⚙️ 配置参考

配置目录是 `plugins/CloudFashion/`。插件当前生成或读取以下文件：

| 文件 | 用途 | 生效方式 |
| --- | --- | --- |
| `settings.yml` | Debug、预览、BossBar、装备信息继承和商城隐藏 | `/cf reload` |
| `database.yml` | SQLite / MySQL 选择和连接地址 | 完整重启 |
| `datasource.yml` | HikariCP 连接池参数 | 完整重启 |
| `fashion/default.yml` | 默认时装定义 | `/cf reload` |
| `fashion/*.yml` | `fashion` 文件夹内新增的时装定义 | `/cf reload` |
| `gui/shop.yml` | 时装商城和分类 | `/cf reload` |
| `gui/wardrobe.yml` | 时装衣橱 | `/cf reload` |
| `gui/slots.yml` | 时装槽位 | `/cf reload` |
| `gui/admin.yml` | 管理员列表和编辑器 | `/cf reload` |
| `lang/zh_CN.yml` | 中文消息和帮助 | 重启后读取 |

## 🧩 settings.yml

```yaml
# 调试设置。仅排查问题时开启，日志量会明显增加。
debug:
  enabled: false

# 时装设置
fashion:
  # 试穿时长 (秒)
  previewTime: 10
  # 预览冷却 (秒)
  previewCooldown: 60
  # 是否将玩家实际穿戴物品的名称、Lore、附魔、属性和耐久等复制到时装视觉物品。
  inheritItemMeta: true
  shop:
    # 是否在商城中隐藏玩家已经购买或通过权限解锁的时装。
    hideAvailable: true

# 预览倒计时 BossBar
preview:
  bossbar:
    enabled: true
    # 可用占位符: {fashion}(时装展示名), {remaining}, {total}
    title: "&e正在预览 &f{fashion} &7| 剩余 &e{remaining}秒"
    color: YELLOW
    # SOLID, SEGMENTED_6, SEGMENTED_10, SEGMENTED_12, SEGMENTED_20
    style: SOLID
```

| 路径 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `debug.enabled` | 布尔值 | `false` | 输出时装数据包、视觉缓存和创造背包操作日志；仅排障时开启。 |
| `fashion.previewTime` | 整数秒 | `10` | 试穿时长，范围 1 至 86400；超出范围回退到 10。 |
| `fashion.previewCooldown` | 整数秒 | `60` | 预览结束后的冷却时间，范围 0 至 86400。 |
| `fashion.inheritItemMeta` | 布尔值 | `true` | 是否复制实际装备的名称、Lore、附魔、属性等，同时保留时装样式。默认文件明确配置为 true；键缺失时源码回退为 false。 |
| `fashion.shop.hideAvailable` | 布尔值 | `true` | 是否隐藏已购买或权限解锁的商城时装。 |
| `preview.bossbar.enabled` | 布尔值 | `true` | 是否显示预览倒计时 BossBar。 |
| `preview.bossbar.title` | 文本 | 见上方 | 支持 `{fashion}`、`{remaining}`、`{total}`。 |
| `preview.bossbar.color` | `BarColor` | `YELLOW` | 支持 Bukkit 的 BossBar 颜色枚举。 |
| `preview.bossbar.style` | `BarStyle` | `SOLID` | 支持 `SOLID`、`SEGMENTED_6`、`SEGMENTED_10`、`SEGMENTED_12`、`SEGMENTED_20`。 |

### 🐞 Debug 日志

将 `debug.enabled` 改为 `true` 后执行 `/cf reload` 即可启用。每条日志包含连续的 `[Debug #编号]`，常见分类如下：

| 分类 | 含义 |
| --- | --- |
| `VISUAL_CACHE` | 玩家当前槽位、手持类型和时装缓存发生刷新。 |
| `SEND_EQUIPMENT` | 插件替换了发往观察者的实体装备包。 |
| `SEND_SET_SLOT` / `SEND_CONTENT` | 插件替换了玩家自身背包的单槽位或完整内容包。 |
| `RECV_CREATIVE_SLOT` | 创造客户端向服务器提交槽位物品，包括 AIR。 |
| `BUKKIT_CREATIVE` | Bukkit 收到的创造背包动作、槽位、当前物品和 cursor。 |
| `SKIP_CREATIVE_*` | 创造模式安全保护已跳过玩家自身的视觉替换或主动刷新。 |

Debug 会显著增加控制台输出。完成复现并保存相关连续日志后，应将开关恢复为 `false`。

### 🛡️ 创造模式显示规则

创造模式的槽位内容由客户端通过 `ServerboundSetCreativeModeSlotPacket` 直接提交。若客户端收到与服务器真实物品不同的视觉时装，点击背包时可能把视觉物品或 AIR 写回真实槽位。

因此插件采用以下固定保护规则：

- 创造玩家自己的背包槽位不应用物品式时装替换。
- 插件不会主动向创造玩家本人发送时装装备刷新，也不会在常规缓存刷新中反复刷新其完整背包。
- 切换到创造模式时会同步一次真实库存，清除客户端残留的视觉状态。
- 其他玩家观察该创造玩家时仍会看到正常时装外观。

该保护不是可关闭选项。ModelEngine / BetterModel 的独立模型不通过背包物品替换，但其实际可见范围仍取决于对应模型插件。

## 🗄️ database.yml

```yaml
# SQLite适用于单端 MYSQL适用于群组服务器

SQLite:
  file: "CloudFashion.db"
MYSQL:
  # 是否开启 不开启默认使用SQLite
  enable: false
  # 数据库IP
  host: localhost
  # 数据库端口
  port: 3306
  # 数据库用户名
  user: root
  # 数据库密码
  password: your_password
  # 数据库名称
  database: cloudfashion
```

| 路径 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `SQLite.file` | 文件路径 | `CloudFashion.db` | SQLite 文件；路径必须位于插件数据目录内。 |
| `MYSQL.enable` | 布尔值 | `false` | 为 `true` 时使用 MySQL，否则使用 SQLite。 |
| `MYSQL.host` | 文本 | `localhost` | MySQL 主机。 |
| `MYSQL.port` | 整数 | `3306` | MySQL 端口。 |
| `MYSQL.user` | 文本 | `root` | MySQL 用户名。 |
| `MYSQL.password` | 敏感文本 | `your_password` | MySQL 密码，请替换为真实值且不要提交到公开仓库。 |
| `MYSQL.database` | 文本 | `cloudfashion` | MySQL 数据库名称。 |

## 🔗 datasource.yml

```yaml
DefaultSettings:
  # 是否自动提交 SQL，默认值 true。
  AutoCommit: true
  # 最小空闲连接数，单位为连接数。
  MinimumIdle: 1
  # 最大连接数，单服默认 10；按数据库容量调整。
  MaximumPoolSize: 10
  # 校验连接超时时间，单位毫秒。
  ValidationTimeout: 5000
  # 获取连接超时时间，单位毫秒。
  ConnectionTimeout: 30000
  # 空闲连接超时时间，单位毫秒。
  IdleTimeout: 600000
  # 连接最大生命周期，单位毫秒。
  MaxLifetime: 1800000
  # 保活间隔，单位毫秒；0 表示关闭。
  KeepaliveTime: 300000
```

这些参数由 HikariCP 使用，修改后必须完整重启。时间单位均为毫秒，连接数参数应结合数据库容量调整。

## 👗 fashion/default.yml

`fashion/` 文件夹会扫描所有 `.yml` 和 `.yaml` 文件。每个时装 ID 必须全局唯一；新增文件的叶子字段与下方配置相同。

```yaml
# 时装类型:
# 装备: Balloon(气球) Backpack(背部) Helmet(头盔) Chestplate(胸甲) Leggings(护腿) Boots(靴子)
# 武器: Sword(武器) Trident(三叉戟) Bow(弓) Crossbow(弩) Shield(盾牌) Mace(重锤)
# 工具: Pickaxe(镐子) Axe(斧子) Shovel(锹) Hoe(锄)
# 特殊工具: FishingRod(钓鱼竿) Shears(剪刀)
# Balloon / Backpack 可使用 BetterModel / ModelEngine
# 推荐配置：model.engine 可填写 auto、modelengine 或 bettermodel
# model:
#   engine: bettermodel
#   id: "模型ID"
# betterModel:
#   id: "BetterModel模型ID"
# 旧配置 model: "模型ID"、modelEngine.model 仍然兼容
# 时装物品唯一ID
"default_helmet":
  # 时装类型
  type: "Helmet"
  # 可选权限。玩家拥有此权限时，无需购买或管理员发放即可使用该时装。
  # 留空或删除该配置表示仅通过拥有记录解锁。
  permission: "cloudfashion.fashion.default_helmet"
  # 时装物品源
  item:
    # source:CE:namespace:id 引用 CraftEngine 物品
    # source:IA:namespaceID 引用 ItemsAdder 物品
    # 该配置会用于GUI界面中显示 材质会用于时装
    material: "source:CE:default:topaz_helmet"
    # name lore 等只会在玩家没有穿戴盔甲时显示
    name: "&e黄玉头盔"
    lore:
      - "&e超级炫酷的头盔"
    # 物品自定义模型数据 默认为 -1 不会生效
    customModelData: -1
  # 商城设置：currency 可填写 coins 或 points；未配置价格时不可购买
  shop:
    enabled: true
    currency: points
    price:
      coins: 100
      points: 1000
"default_chestplate":
  type: "Chestplate"
  permission: "cloudfashion.fashion.default_chestplate"

    material: "source:CE:default:topaz_chestplate"

"default_leggings":

    material: "source:CE:default:topaz_leggings"

    enabled: true
    currency: points
    price:
      coins: 100
      points: 1000
"default_boots":
  type: "Boots"
  permission: "cloudfashion.fashion.default_boots"
  item:
    material: "source:CE:default:topaz_boots"
    name: "&e黄玉靴子"
  shop:
    enabled: true

      coins: 100
```

### 时装字段

| 路径 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `<id>.type` | 枚举 | 无 | `Balloon`、`Backpack`、`Helmet`、`Chestplate`、`Leggings`、`Boots`、`Sword`、`Trident`、`Bow`、`Crossbow`、`Shield`、`Mace`、`Pickaxe`、`Axe`、`Shovel`、`Hoe`、`FishingRod`、`Shears` 或 `None`。 |
| `<id>.permission` | 文本 | 未配置 | 拥有该权限即可直接使用时装；权限失效且无持久化拥有记录时清理穿戴。 |
| `<id>.item.material` | 文本 | `air` | 原版材质、XMaterial、`source:CE:<namespace>:<id>` 或 `source:IA:<namespace>:<id>`。 |
| `<id>.item.name` | Legacy 文本 | 未配置 | 时装展示名称；未配置时保留来源物品名称，明确配置 `' '` 才使用空白名称。 |
| `<id>.item.lore` | 文本列表 | `[]` | 时装基础 Lore；继承开关开启且有实际装备时复制实际装备 Lore。 |
| `<id>.item.customModelData` | 整数 | `-1` | 大于 0 时应用原版自定义模型数据。 |
| `<id>.model` | 文本或对象 | 未配置 | 兼容旧模型 ID；推荐使用 `model.engine` 与模型 ID。 |
| `<id>.model.engine` | 枚举 | `auto` | `auto`、`modelengine` 或 `bettermodel`。 |
| `<id>.model.id` | 文本 | 未配置 | 通用模型 ID。 |
| `<id>.modelEngine.model` / `.id` | 文本 | 未配置 | ModelEngine 兼容字段。 |
| `<id>.betterModel.model` / `.id` | 文本 | 未配置 | BetterModel 兼容字段。 |
| `<id>.shop.enabled` | 布尔值 | `true` | 是否在商城上架。 |
| `<id>.shop.currency` | 枚举 | `coins` | `coins` 或 `points`。非法值回退 `coins`。 |
| `<id>.shop.price.coins` | 小数 | 未配置 | 金币价格；小于 0 的值视为未配置。 |
| `<id>.shop.price.points` | 整数 | 未配置 | 点券价格；小于 0 的值视为未配置。 |

无效类型会跳过该时装；重复 ID 会保留先加载的定义并跳过后续定义。旧版插件数据目录根部的 `fashion.yml` 会在 `fashion/default.yml` 不存在时迁移为 `fashion/default.yml`；如果目标文件已存在，旧文件不会加载。
